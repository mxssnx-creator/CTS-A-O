# Base Last-N 60 and Validation Last-N 8, 10, 12 — 28 October 2026

This is a retrospective, unallocated model replay of previously examined 20-symbol Binance USD-M minute candles, **not** an untouched holdout, exchange fill, funded account return, or evidence of consistently high PF. Historical validation is 2026-10-08 12:00–2026-10-09 12:00 UTC; the subsequent forward period is 2026-10-09 12:00–2026-10-10 12:00 UTC. All values use gross gains divided by absolute gross losses on per-unit returns, including one modeled 0.15% round-trip cost. Overlapping configurations are independent modeled orders, not a funded portfolio.

The frozen scope is Short range Low-Range cells, 1m/5m/15m, Normal and capped Trailing, 60-minute maximum hold and no Block, DCA, Axis or Historic Exit. The 3,900-cell screen applies an **additional counterfactual Base Last-N 60 after the existing aggregate Base gate**; this is not a configurable production Base Last-N. Validation is `validLastN=8`, `10`, or `12`, with the range Last-N gate 75 and min PF 1.35, warmup and minimum sample gates enabled. On x01 mainnet, the runtime normally floors Validation Last-N at **50** unless the host explicitly waives the floor; no host setting was changed in this study.

Thus this is not evidence that a strict 60-close minimum has been tested.

This verifies these modeled paths, not exchange-side TP/SL placement or actual fees. Adding the modeled cost back to the **same** walk-forward closes gives gross PF 2.1306 / 1.5029 / 1.8817 for Validation 8/10/12. This is arithmetic on an unchanged cohort, not a zero-fee resimulation; fees materially reduce PF here, but venue commissions and slippage are unmeasured. A separate earlier 5m study found 60 minutes best of the tested 15/30/60/180-minute holds, yet its forward PF remained below 1. It does not establish an optimal hold outside that cohort. The hourly selected counts and individual check records are preserved with the evidence. These counts identify decision points, not proof of a specific bug causing the difference between the historical and forward periods.

## Selection fixes and verification

Two independently reproduced selector defects were corrected: Signal branches of `selectAt` and `selectDurable` now honor an explicit validated set, and the fixed-selector cache refreshes when membership changes inside the same Set object. Regression tests demonstrate a removed config cannot retain its seat, restoring membership works, and explicit pool mode remains available. The normal walk-forward route splits Signals and normally uses fixed validated sets; the evidence does **not** establish that these bugs caused the measured drop in this static-set Low-Range replay.

Focused tests cover selector membership and mutation, Signal lanes, execution identity, continuous validation, range options, simulation parity, runtime mainnet Last-N floors and the independent price-path auditor. Type checking and targeted lint were run. This evidence does not certify every strategy or live account; actual funded settled PF, actual fee provenance and venue fill/exit behavior remain unavailable. Changing modeled cost while an ordinary paper position is held remains a known issue requiring entry-cost provenance; no accounting behavior was changed here.
